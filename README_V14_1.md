V14.1 - Pantalla de configuración de Contasimple.

El administrador puede introducir desde el programa:
- URL del portal
- URL de la API
- Client ID
- Client Secret
- Redirect URI
- Endpoint de creación de albaranes

Los tokens OAuth2 se guardan en PostgreSQL. No se guarda la contraseña del usuario de Contasimple.
Contasimple documenta Authorization Code Grant y refresh tokens.
